# Edge AI report archive

Static GitHub Pages site for research visualizations.

- Index: `index.html`
- Week 2: `reports/week-02/humbug-data-audit/index.html`
- Downloadable tables: alongside the report in `tables/`
- Images and listening excerpts are embedded in the report.

Add later reports under `reports/week-NN/analysis-name/` and add an entry to the index.
Preserve published paths so links in previously distributed PDFs remain valid.
State each report's dataset version, saved-run date, and analytical scope.
Only reviewed publication files belong in this site; do not copy raw project directories.

Publishing source: branch `codex/report-site`, root directory. The main project branch is independent.
